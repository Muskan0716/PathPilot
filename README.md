# PathPilot – Student Career Guidance and Roadmap Platform

## About the Project

PathPilot is a web-based Student Career Guidance Platform designed to help students discover suitable career opportunities, understand the skills required for their desired careers, and follow personalized learning roadmaps.

It helps students plan their career journey through career recommendations, project suggestions, learning milestones, and progress tracking.

## Features

### 1. Student Profile
- Create and manage student profiles.
- Add educational details and courses.
- Add technical skills and interests.
- Mention experience and career goals.

### 2. Career Recommendations
- Recommends suitable career paths based on student profiles.
- Matches students' skills and interests with career options.
- Displays career descriptions and required skills.

### 3. Roadmap Generator
- Generates step-by-step learning roadmaps.
- Provides skills to learn for the selected career.
- Helps students follow structured learning milestones.

### 4. Progress Tracker
- Track learning progress.
- Mark roadmap tasks as completed or incomplete.
- Monitor completed learning milestones.

### 5. Project Suggestions
- Provides project ideas based on career interests.
- Includes beginner, intermediate, and advanced project levels.
- Helps students gain practical experience.
